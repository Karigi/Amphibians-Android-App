## AMPHIBIANS APP
- This app displays different kinds of amphibians with a title an image and description.
    The data is sourced from an online server using retrofit. 
- Kotlin is used as the programming language (JetPack Compose)

### Concepts Applied
1. Retrofit
2. OkHttpClient for interceptors and time outs
3. Separation of data and UI layer
4. Layout Design for different screen width sizes
5. Material3 Theme Builder for theme and typography
6. Coroutines are used for expensive network calls and concurrency 
7. Hilt for dependency injection
